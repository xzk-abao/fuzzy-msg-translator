# 示例：bug / 数据异常场景（客户原话 → 4 件套）

**客户发来的：**

> 客户列表里的电话怎么是旧的？保存了也不变啊

---

## ① 卡片（自己看的，不发微信）

```
场景：bug/数据异常
原话：客户列表里的电话怎么是旧的？保存了也不变啊
已确认：
  - 位置：客户列表页电话列
  - 现象：保存后电话仍显示旧值
待确认：
  - 对比两端：和详情页/编辑框里的值是否一致？
  - 范围：全部客户还是部分？
```

## ② 话术（直接复制进微信，3 条气泡）

```
这个我知道哪的问题，列表里的电话没跟着改是吧
你保存完是刷新了列表看的吗？截一张列表的图发我
我看下是缓存没刷还是压根没存上。顺带问下，所有客户都这样还是就这几个？
```

每条的逻辑：
- 第 1 条 = 复述，证明听懂了（猜想在里面："列表电话没跟着改"）
- 第 2 条 = 带用途要截图（区分"缓存没刷"和"数据没存上"两个猜想）
- 第 3 条 = 定范围（全部 → 查全局配置/列表查询逻辑；部分 → 查单条数据）

## ③ 回写（槽位问完锁定边界时发）

```
对一下啊：就是保存后列表页电话不变、应该变新的，你希望保存完刷新列表就是新值，我按这个查，对吧
```

## ④ 任务记录（转译分析完成立即落，不等回写）

```
| T-001 | 客户A | bug | 客户列表页电话保存后不更新 | P1 | 待确认 | 11-13 | | 待确认槽位：对比两端/范围 |
```

优先级判 P1：数据错，可能影响客户联系；没卡住主流程，不到 P0。
