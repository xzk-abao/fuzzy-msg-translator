# fuzzy-msg-translator（微信模糊消息转译器）

客户/同事在微信里发来一句话：

> "数据对不上，你处理一下"

位置、现象、期望、边界全是空的。你回"具体是哪里的数据？"，对方回"你自己不会看吗"。

这个仓库把「把一句模糊感受，现场转译成一份最小可执行的问题定义」做成了一个可直接复制进 Claude Code 的 Skill + 两套任务/验证记录模板。输入一句消息，输出四件套：

1. **槽位卡片**：已确认的信息 + 还缺什么（不脑补，缺的标"待确认"）
2. **人话话术**：2-3 条可以直接复制进微信的短气泡，带逻辑链（复述→猜想→提问），不是"请详细描述"
3. **回写**：一句话把边界锁死——"就是列表页电话保存后没跟着改，你希望两边一致，我按这个查，对吧"
4. **任务记录**：一到就记，走 `待确认 → 待排期 → 进行中 → 待验证 → 已关闭` 状态机，P0/P1/P2 排期，多人并发发需求不混乱

## 完整示例（客户原话 → 4 件套）

**客户发来的：**

> 客户列表里的电话怎么是旧的？保存了也不变啊

**① 卡片（自己看的）**

```
场景：bug/数据异常
原话：客户列表里的电话怎么是旧的？保存了也不变啊
已确认：
  - 位置：客户列表页电话列
  - 现象：保存后电话仍显示旧值
待确认：
  - 对比两端：和详情页/编辑框里的值是否一致？
  - 范围：全部客户还是部分？
```

**② 话术（直接复制进微信，3 条气泡）**

```
这个我知道哪的问题，列表里的电话没跟着改是吧
你保存完是刷新了列表看的吗？截一张列表的图发我
我看下是缓存没刷还是压根没存上。顺带问下，所有客户都这样还是就这几个？
```

每条都有逻辑：第 1 条=复述证明听懂；第 2 条=要截图并说明用途（区分两个猜想）；第 3 条=定范围（全部→查全局配置，部分→查单条数据）。

**③ 回写（槽位问完锁定边界）**

```
对一下啊：就是保存后列表页电话不变、应该变新的，你希望保存完刷新列表就是新值，我按这个查，对吧
```

**④ 任务记录（分析完成立即落，不等回写）**

```
| T-001 | 客户A | bug | 客户列表页电话保存后不更新 | P1 | 待确认 | 11-13 | | 待确认槽位：对比两端/范围 |
```

## 安装（Claude Code）

1. 把 `skill/` 目录复制到 `~/.claude/skills/fuzzy-msg-translator/`
2. 把 `templates/` 里的两个模板复制到你自己的工作目录（任务表要每天翻，放手边）
3. 收到模糊消息时直接说："帮我转译这条：xxx"

## 目录

```
skill/SKILL.md             引擎（槽位模板 + 人话规则 + 状态机）
templates/task-log.md      任务记录模板（进行中/已关闭两张表）
templates/verify-log.md    验证记录模板（回填追问逻辑用）
examples/example-bug.md     完整示例 1：客户原话 → 4 件套（bug 场景）
examples/example-feature.md 完整示例 2：同事原话 → 4 件套（模糊需求场景）
```

## 边界（三条）

- 只生成草稿，不自动发送——发送永远是你本人
- 不读微信本地数据库（进阶 MCP 路径有封号风险，本仓库不提供）
- 不存储原始聊天记录——原始消息只在对话里过一遍，不落库
